# TAJ Engineering & Project Services — Website

Static site, no build step: plain HTML/CSS/JS. Open `index.html` directly in a browser, or serve the folder with any static file server.

## Deployment

Everything in this repository is meant to be published as-is: `index.html`, `404.html`, `privacy.html`, `terms.html`, `manifest.webmanifest`, `robots.txt`, `sitemap.xml` and `assets/`.

## Domain

Production domain is **tajengineering.com.ng** — wired into `robots.txt`, `sitemap.xml`, the `<head>` meta tags in `index.html` (canonical, `og:url`, `og:image`, `twitter:image`) and the `url` field in the JSON-LD schema block. As of this writing the domain doesn't yet resolve to a live site — confirm DNS/hosting is pointed at it before relying on these URLs being reachable.

## Photography

`hero-engineers.webp`, `property-exterior.webp`, `project-monitoring.webp` and `building-inspection.webp` are AI-generated (via ChatGPT), matched to the hero image's art direction: TAJ-branded hi-vis vest (navy logo lockup, matches `assets/logo.svg`), Nigerian residential/site context, no faces, no legible foreign text or branding. Generated at 1536×1024; swapped in at native resolution with no crop needed since none of the identity/legibility issues that affected earlier stock-photo picks apply here. Regenerate via ChatGPT using the same style brief if these ever need a refresh, and swap out for real TAJ project photography as soon as there's a first inspection or monitoring visit on file — that's still the highest-trust upgrade available, AI-generated or not.

`project-records.webp` remains Pexels stock (free-license, no attribution required): "Sheets of Paper with Floor Plan and Contract," photo by Thirdman, pexels.com/photo/8470057 — a document flatlay with no people, so it never carried the face/location-mismatch risk the others did, and reads fine sitting next to the AI-generated images.

## Evidence maintenance

See `EVIDENCE_SOURCES.md` before editing the source-backed carousel. Keep all claims attributed to the named source and do not convert an allegation, preliminary finding or regulatory concern into a final technical cause.

## Professional boundaries

TAJ's website describes owner-side inspections, monitoring, documentation and coordination. Formal structural certification, statutory design responsibility, laboratory testing and other regulated opinions remain separate scopes handled by appropriately registered professionals where required.
